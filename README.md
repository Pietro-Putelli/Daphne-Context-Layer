# Daphne

Daphne is a knowledge workspace for engineering teams. Its first release will help engineers answer questions like “Why did we make this decision?” using GitHub, team docs, and uploaded files. Answers will cite the exact source versions the reader can access and flag gaps in the evidence. Maintainers will be able to correct, approve, or retire team guidance.

Today the repo runs a Next.js landing page, a database health endpoint, and local PostgreSQL with pgvector.
